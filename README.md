# منصة رياض الصالحين الذكية 🎓

## نظام المؤشرات والاستبيانات الذكي

منصة ويب متقدمة لمدارس رياض الصالحين تجمع بين:
- 📊 **مؤشرات الأداء**: تتبع مستويات الرضا والأداء
- 📋 **الاستبيانات الذكية**: جمع آراء الطلاب والمعلمين وأولياء الأمور والإداريين
- 📈 **التحليلات**: رسوم بيانية وتقارير مفصلة
- 🎯 **الإدارة**: تحسين مستمر بناءً على البيانات

## المميزات الرئيسية

✅ واجهة عربية RTL احترافية
✅ استبيانات ديناميكية قابلة للتخصيص
✅ رسوم بيانية تفاعلية بـ Chart.js
✅ نظام تقييم شامل
✅ تقارير تفصيلية

## التثبيت والتشغيل

1. استنساخ المستودع
2. فتح `index.html` في المتصفح
3. أو استخدام خادم محلي:
```bash
python -m http.server 8000
```
